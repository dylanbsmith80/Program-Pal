# Program Pal Facility Profiles

Use this repository-tracked reference for non-sensitive facility layout and equipment context. Client-specific health, preference, and program records still belong only in the client's private Google Drive memory.

Source: trainer statement in task, 2026-08-30.

## Default Facility Rule

- Assume every training session takes place at **North Rec** unless the trainer explicitly says **South Rec**.
- Do not infer that South Rec has the same layout or equipment. When South Rec is specified, use only equipment confirmed for that session or ask for the missing facility details when they affect program design.
- Treat an explicit session location from the trainer as authoritative over this default.

## North Rec

North Rec has three floors. Build practical session flow by grouping exercises on the same floor when possible. Avoid unnecessary floor changes, especially during supersets, circuits, buddy rotations, and short sessions. When a floor change is useful, make it a deliberate block transition.

### First Floor — Heavy Strength And Free Weights

Available equipment and spaces:

- Free-weight stations for barbell squat, bench press, deadlift, and other barbell movements
- Benches and a dumbbell area with additional benches
- Straight barbells and EZ-curl bars
- Boxes for box jumps, split squats, and related movements
- Kettlebells
- TRX area
- Standard cable towers
- Heavy lat-pulldown and cable-row stations
- Plate-loaded row, lat pulldown, chest press, and shoulder press machines
- Extensive cardio equipment

Programming rules:

- Program heavy barbell work, substantial dumbbell work, plate-loaded work, and heavy kettlebell work on this floor.
- Use the first floor for heavy lat pulldowns and heavy cable rows. Standard cable towers exist on all three floors, but the heavier dedicated pulling stations are on the first floor.
- Program heavy loaded carries, including heavy farmer's carries, on this floor because the necessary weights are here.
- Free-weight and machine work can often be grouped into a first-floor strength block to reduce transitions.

### Second Floor — Selectorized Machines And Cable Accessories

Available equipment and spaces:

- Leg-extension machine
- Seated hamstring-curl machine
- Hip-abductor and hip-adductor machines
- Selectorized shoulder-press and chest-press machines
- Assisted dip and assisted pull-up machine
- Cable stations suitable for chest fly variations, accessory pulldowns, kickbacks, and cable step-ups
- Pec-deck machine
- Cardio equipment
- Row ergometer
- Very light dumbbells

Programming rules:

- Use this floor for selectorized lower-body accessories, assisted bodyweight movements, pec-deck work, and lighter cable accessories.
- Do not plan normal or heavy dumbbell training here; only very light dumbbells are available.
- Do not substitute a second-floor cable setup for the first-floor heavy lat-pulldown or cable-row stations when substantial loading is required.

### Third Floor — Core, Mobility, Circuits, And Open Space

Available equipment and spaces:

- The most open floor space for core work and circuits
- Space for walking and movement-based drills
- TRX space
- Standard cable towers
- Medicine balls
- Bulgarian bags and other less-common training implements
- Miscellaneous machines

Programming rules:

- Prefer this floor for core blocks, mobility work, stretching, movement circuits, TRX work, and light loaded work that needs open space.
- Use this floor for circuits when the chosen equipment is available and the circuit does not require heavy weights from the first floor.
- Keep heavy farmer's carries and other heavy loaded carries on the first floor. Lighter carries or movement drills may use the third floor when appropriate.

## Session-Flow Guidance

- Use the same lettered block for multiple movements only when they share the same equipment or station. Same-floor proximity by itself does not make a pairing practical.
- If two movements require different machines, benches, cable towers, racks, or gym areas, place them in separate sequential blocks even when both are on the same floor.
- Never program a cross-floor superset, circuit pairing, or buddy rotation unless the trainer explicitly requests it.
- For buddy sessions, confirm both participants can rotate within the same floor or station cluster without losing meaningful work time.
- A common North Rec flow may begin with heavy strength on the first floor, move to second-floor machine accessories if needed, and finish with third-floor core or mobility. This is an option, not a required template.
- Prefer a same-floor substitute when changing floors would add more disruption than programming value.
- Record a client-specific facility exception in private client memory only when it is durable and relevant, such as a confirmed equipment restriction or an explicit usual location other than North Rec.
